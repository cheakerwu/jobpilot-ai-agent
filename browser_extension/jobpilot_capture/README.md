# JobPilot 岗位采集插件

这是 JobPilot 的本地浏览器插件雏形，用于把用户当前打开的招聘岗位页面保存到本地岗位池。

## 当前能力

- 连接本地已登录的 JobPilot Web 页面，读取本地登录 token。
- 在当前招聘页读取页面标题、链接、选中文本和页面正文。
- 调用 `POST /api/imports/capture` 保存岗位。
- 可选择保存后规则分析，或启用 AI 分析。

## 本地加载

1. 打开 Chrome / Edge 的扩展管理页。
2. 开启开发者模式。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录：

```text
D:\code\job_agent\browser_extension\jobpilot_capture
```

## 使用方式

1. 启动 JobPilot，并在浏览器里登录，例如 `http://127.0.0.1:8787/app`。
2. 点击扩展图标，确认 JobPilot 地址。
3. 点击“连接已登录页面”。
4. 打开招聘岗位页面，最好先选中岗位正文。
5. 点击“保存当前岗位”。

插件只在用户点击时读取当前页面内容，不做后台自动爬取、不自动翻页、不模拟登录招聘平台。
